**Caddy** provides syntax highlighting and autocompletion for **the [Caddy](https://caddyserver.com) webserver** configuration files.

![](https://nova.app/images/en/dark/editor.png)
![](https://nova.app/images/en/dark/editor.png)

## Language Support

Caddy uses the upstream tree-sitter-caddyfile repository, with customized highlight naming to better match Nova's defaults.

Caddy also symbolizes the Caddyfile.
